Instalación en 2 pasos

1. Descarga el archivo .tar.gz (incluye el binario, el lanzador gráfico y las dependencias).
2. Extrae y haz doble clic en burner.sh ¡Listo!

$ tar -xzf Memexicanisimos-Burner.tar.gz
$ cd Memexicanisimos-Burner && ./burner.sh

¿Prefieres usar la terminal? sha256sum -c Memexicanisimos-Burner.tar.gz.sha256 para verificar.

¿Por qué elegir Memexicanisimos Burner?

División automática de WIM

Divide install.wim en fragmentos .swm compatibles con FAT32 sin intervención manual.

Instalación de dependencias con un clic

Si falta alguna herramienta, la app te ofrece instalarla gráficamente sin abrir la terminal.

Verificación SHA256 integrada

Confirma la integridad de la ISO en segundo plano y evita errores de instalación.

¿Eres desarrollador? Compila tu propia versión

Clona el repositorio, instala las dependencias y ejecuta el script de compilación.

# Clonar y preparar entorno
$ git clone https://github.com/myinnervoid/Memexicanisimos-Burner-Windows.git
$ cd Memexicanisimos-Burner-Windows
$ python3 -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt
# Generar ejecutable portable
$ ./build_portable.sh
